    D2How long should a reset link stay valid?

    answered

    E1 stores the expiry with every token (app/resets.py:24), so this had to be settled before the first test.

    OptionGainsCosts
    30 minutesA forwarded or leaked email is useless quicklySlow mail can make a few links expire
    24 hoursFewer "link expired" complaintsA day-long window for a leaked email

    Recommendation: 30 minutes, in line with the OWASP guidance.

    Cost to change later
    Low: one constant, RESET_TTL at app/resets.py:9.
